# Rigi Extensions 1.5.51

Publication-ready release bundle created on 2026-08-14.

The primary product name and logo changed. The Swiss editorial UI, alpine background, red accent, and individual tool names remain unchanged. This build also repairs grayscale site favicons on suspended tabs after a browser restart.

## Files

- `RigiExtensions-v1.5.51-chrome-store.zip` — upload to Chrome Web Store as the extension package.
- `RigiExtensions-landing-v1.5.51.zip` — deploy the archive contents as the landing site.
- `RigiExtensions-store-assets-v1.5.51.zip` — screenshots, promotional images, store icon, and listing copy.
- `chrome-web-store-assets/` — unpacked Store assets for direct upload.

## Store upload order

1. Upload the extension ZIP.
2. Copy the EN listing and release notes from `chrome-web-store-assets/STORE_LISTING.md`.
3. Upload `store-icon-128.png`.
4. Upload screenshots `01` through `05` in filename order.
5. Upload the small and marquee promotional images.
6. Confirm the existing privacy-policy URL and permission justifications before submission.

Previous rejected naming concepts are stored under `legacy-navorina/` and `legacy-swiss/`; do not upload those files.
