# Chrome Web Store assets — Rigi Extensions

Ready-to-upload files are in `final/`.

## Upload mapping

- Store icon: `store-icon-128.png` — 128 × 128
- Screenshots, in recommended order:
  1. `screenshot-01-overview-1280x800.png`
  2. `screenshot-02-command-1280x800.png`
  3. `screenshot-03-lens-1280x800.png`
  4. `screenshot-04-hibernate-1280x800.png`
  5. `screenshot-05-blocker-1280x800.png`
- Small promotional image: `promo-small-440x280.png`
- Marquee promotional image: `promo-marquee-1400x560.png`

All screenshots and promotional images are opaque PNG files with the exact Chrome Web Store dimensions.

## Art direction

The publication set uses the original Rigi ridge mark, restrained Swiss editorial typography, the existing mountain background, and real captures from the current extension UI. It does not use the official Swiss cross.

Canonical editable sources and the renderer live in `../../brand-assets/navorina-extensions/`.
